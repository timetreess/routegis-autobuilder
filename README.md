# RouteGIS AutoBuilder

<p align="center">
  <img src="plugin/icon.png" alt="RouteGIS AutoBuilder 아이콘" width="96">
</p>

> 토목 노선 도면(DXF) 한 장으로, 사업구간 주변 공간정보가 정리된 QGIS 프로젝트를 자동으로 만드는 QGIS 플러그인

| | |
|---|---|
| **누구를 위한 도구인가** | 도로·철도 등 토목 사업의 설계·입찰·기술검토 담당자 |
| **무엇을 해결하나** | 노선 검토 초기에 도면을 GIS로 옮기고 주변 공간정보를 모으는 반복 작업 |
| **무엇이 나오나** | 바로 열어 검토할 수 있는 QGIS 프로젝트, 공유용 HTML 지도, 처리 보고서 |
| **어디서 쓰나** | Windows PC의 QGIS 3.34 이상 3.x |

---

## 왜 만들었나

노선 검토를 시작할 때는 도면만 있고 주변 현황 자료는 없는 경우가 많습니다. 담당자는 사업구간 주변에 보호구역, 토지 소유, 하천, 송전선로가 있는지 확인하려고 매번 같은 일을 반복합니다.

| 작업 | 지금까지 (수작업) | RouteGIS AutoBuilder |
|---|---|---|
| 도면을 지도 데이터로 변환 | CAD에서 내보내고 GIS에서 다시 정리 | DXF를 선택하면 모든 선 객체를 자동 변환 |
| 좌표계 확인 | 경험에 의존, 틀리면 엉뚱한 위치에 표시 | 도면 좌표와 사업 지역으로 후보 추천, 지도에 겹쳐 확인 |
| 사업구간 주변 범위 설정 | 직접 작도 | 거리(m)만 입력 |
| 주변 공간정보 수집 | 기관별 사이트에서 하나씩 내려받기 | VWorld·국립생태원·OpenStreetMap에서 자동 수집 |
| 레이어 정리 | 파일마다 불러와 분류·색상 지정 | 분야별 그룹과 스타일이 적용된 프로젝트 생성 |
| 결과 공유 | 폴더 전체를 압축해 전달 | HTML 파일 하나만 전달 |
| 작업 기록 | 남지 않음 | 데이터 출처·라이선스·실패 원인을 보고서에 기록 |

데이터 변환과 수집에 쓰던 시간을 줄여, 담당자가 실제 검토에 더 빨리 들어갈 수 있게 하는 것이 목표입니다.

## 결과물

프로젝트를 만들면 사업명 폴더 안에 다음 파일이 생깁니다.

| 결과 | 용도 |
|---|---|
| `<사업명>.qgz` | QGIS에서 바로 여는 프로젝트. 분야별 그룹·스타일과 노선 범위 화면이 설정되어 있습니다. |
| `<사업명>.html` | 공유용 웹 지도. 파일 하나만 보내면 받는 사람이 브라우저로 열어 봅니다. |
| `data/project.gpkg` | 모든 분석 데이터 (GeoPackage) |
| `shp/` | 분야별 Shapefile (국내 CAD/GIS 프로그램 호환용) |
| `reports/` | 레이어별 성공·실패, 객체 수, 출처를 정리한 처리 보고서 (HTML, JSON) |
| `source/` | 실행에 사용한 원본 도면 사본 |
| `project_manifest.json` | 입력값, 좌표계, 레이어, 실행 상태 기록 |
| `logs/app.log` | API Key가 제거된 실행 로그 |

QGIS 프로젝트는 `01_노선`, `02_생태환경`, `03_국가유산`, `04_수자원`, `05_전력시설`, `10_토지`, `11_기본도` 등 분야별 그룹으로 정리됩니다. 범위 안에 객체가 없는 그룹은 `(해당없음)`으로 표시됩니다.

**HTML 웹 지도**는 지도 프로그램, 스타일, 데이터가 모두 파일 하나에 들어 있어 QGIS가 없는 사람도 확대·이동, 레이어 켜고 끄기, 객체 클릭 속성 조회를 할 수 있습니다. 배경지도(VWorld 일반지도)만 인터넷을 사용하고, **배경지도 없음**을 고르면 오프라인으로도 볼 수 있습니다. 원본 CAD 도면은 넣지 않지만 수집한 공간정보와 속성은 들어 있으므로, 외부 공유 전에 사내 보안 기준과 공급기관 이용 조건을 확인하세요.

## 기본으로 수집하는 공간정보

| 공간정보 | 공급기관 |
|---|---|
| 생태자연도 | 국립생태원 |
| 토지소유공간정보 | VWorld (국토교통부) |
| 국가유산 지정·보호구역 | VWorld (국토교통부) |
| 송전선로 | OpenStreetMap |
| 송전철탑·지지물 | OpenStreetMap |
| 하천구역·수면 | OpenStreetMap |

하천 중심선, 행정경계, 용도지역 등은 목록에서 추가로 선택할 수 있습니다. **브이월드 목록 불러오기**를 누르면 VWorld가 제공하는 다른 레이어도 고를 수 있습니다.

## 설치

1. [최신 릴리즈](https://github.com/timetreess/routegis-autobuilder/releases/latest)에서 **`routegis_autobuilder.<버전>.zip`**을 내려받습니다. `Source code (zip)`은 설치용 파일이 아닙니다.
2. **ZIP은 압축을 풀지 않습니다.**
3. QGIS에서 **플러그인 → 플러그인 관리 및 설치 → ZIP 파일에서 설치**를 열고, 내려받은 ZIP을 선택해 **플러그인 설치**를 누릅니다.
4. **벡터 → RouteGIS AutoBuilder** 또는 툴바 아이콘으로 실행합니다.

업데이트할 때도 새 ZIP을 같은 방법으로 설치하면 됩니다.

## 사용 방법

### 준비물

- **DXF 노선도면.** DWG는 CAD 프로그램에서 DXF로 저장해 주세요.
- **VWorld API Key.** [VWorld](https://www.vworld.kr) 개발자센터에서 발급합니다.
- **공공데이터포털 서비스키.** [공공데이터포털 생태자연도 WFS](https://www.data.go.kr/data/15057288/openapi.do)에서 활용신청합니다.

OpenStreetMap 자료는 Key 없이 수집합니다.

### 4단계로 끝내기

1. **프로젝트 정보 입력.** 사업명, 사업 지역(시·도), 저장 위치, DXF 도면, 두 가지 Key를 입력합니다.
2. **도면 분석.** **도면 분석**을 누르면 도면을 읽고 좌표계 후보를 추천합니다. 지도에서 붉은 도면 선이 실제 도로·하천 위치와 맞는지 확인하고, 맞지 않으면 다른 좌표계를 고릅니다.
3. **범위와 공간정보 선택.** 사업구간 주변 범위(기본 1,000 m)를 정하고, 필요한 공간정보를 체크합니다.
4. **프로젝트 생성.** **프로젝트 생성**을 누르면 진행률과 로그를 보여 주며 수집·저장합니다. 끝나면 QGIS에 프로젝트가 자동으로 열립니다.

> **좌표계 추천은 확정값이 아닙니다.** 위치가 맞지 않는 상태에서 진행하지 말고, 도면 작성에 쓴 좌표계를 확인해 주세요. 좌표계가 틀리면 수집한 자료가 엉뚱한 곳에 놓이므로, 이 단계만큼은 사람이 직접 판단하도록 설계했습니다.

## 문제가 생기면

결과 화면에 레이어별 성공·실패와 원인이 표시됩니다. 자주 보는 경우는 다음과 같습니다.

| 표시 | 뜻과 조치 |
|---|---|
| `INVALID_KEY`, `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | Key가 틀렸거나 서비스 이용 신청이 승인되지 않았습니다. |
| `CERTIFICATE_VERIFY_FAILED` | 사내 보안 프록시의 인증서 문제입니다. 전산 담당자에게 루트 인증서 등록을 확인하세요. |
| OpenStreetMap `HTTP 504` | 서버 혼잡입니다. 잠시 후 다시 실행하세요. |
| `해당없음` | 정상 조회했지만 범위 안에 해당 객체가 없습니다. |
| 자료가 엉뚱한 위치에 표시됨 | 원본 도면 좌표계를 다시 확인하세요. |

자세한 원인과 동작 방식은 [문제 해결과 상세 동작](docs/TROUBLESHOOTING.md)에 정리했습니다.

## 꼭 알아야 할 한계

- DWG는 직접 읽지 않습니다. DXF로 저장한 뒤 사용해야 합니다.
- 문자, 치수, 블록 등은 분석 범위에 포함하지 않습니다. `LINE`, `POLYLINE`, `LWPOLYLINE`, `ARC`만 사용하며, 길이 0인 선은 제외하고 보고서에 경고를 남깁니다.
- 좌표계 추천은 후보일 뿐입니다. 지역 원점·임의 좌표, X/Y가 뒤바뀐 도면, mm 단위 도면은 자동으로 보정하지 않습니다.
- 외부 공간정보의 정확성, 최신성, 이용 가능 여부, 라이선스는 각 공급기관의 정책을 따릅니다.
- 데이터를 내려받았다는 사실이 설계·인허가 적합성을 보증하지는 않습니다.
- 이 도구는 반복 작업을 줄일 뿐, 좌표계 판단과 결과 검토, 최종 기술적 책임을 대신하지 않습니다.

## 설계에서 중요하게 본 것

- **좌표계는 사람이 확정합니다.** 시스템은 후보를 추천하고 지도에서 비교할 수 있게 할 뿐입니다. 내려받은 자료가 사업구간과 전혀 겹치지 않으면 좌표계 오류로 보고 해당 레이어를 실패 처리합니다.
- **일부가 실패해도 결과를 버리지 않습니다.** 한 기관의 서버가 응답하지 않아도 성공한 자료로 프로젝트를 만들고, 실패한 항목과 원인을 보고서에 남깁니다.
- **긴 노선도 끊기지 않게 수집합니다.** 범위를 격자로 나눠 요청하고, 응답 한도에 걸리거나 일시 장애가 난 구간만 더 작게 나눠 다시 요청합니다. 요청 횟수에는 상한을 둡니다.
- **도면은 밖으로 나가지 않습니다.** 공급기관에는 조회 범위, 레이어 ID, 인증키만 보내고, API Key는 결과 파일과 로그에 남기지 않습니다.
- **기존 결과를 망가뜨리지 않습니다.** 임시 폴더에서 완성한 뒤 한 번에 교체하고, 저장에 실패하면 이전 결과를 되돌립니다.
- **품질 관리.** 600개가 넘는 자동 테스트를 실행하고, 릴리즈마다 보안 검사와 예시 데이터 기반 오프라인 빌드를 통과해야 배포됩니다.
