# Security Policy

## Supported versions

Security fixes are provided for the latest published `0.2.x` release.

## Reporting a vulnerability

Do not disclose a suspected vulnerability, credential exposure or unsafe file-handling issue in a public GitHub issue. Use [GitHub private vulnerability reporting](https://github.com/timetreess/routegis-autobuilder/security/advisories/new) and include:

- the affected version;
- reproduction steps or a proof of concept;
- the potential impact;
- any suggested mitigation.

You should receive an acknowledgement within five business days. API keys and project drawings must never be attached to a report unless a secure transfer method has been agreed first.

For general bugs and questions, use [GitHub Issues](https://github.com/timetreess/routegis-autobuilder/issues). The GitHub noreply address in package metadata identifies the author and is not a support mailbox.
