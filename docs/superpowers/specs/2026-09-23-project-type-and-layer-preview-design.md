# 사업 유형별 DXF 처리 및 선형 후보 미리보기 설계

## 목표

- VWorld 레이어 검색이 표시명, RouteGIS 내부 ID, VWorld `data_id`를 모두 찾는다.
- 사용자가 DXF 분석 직후 사업이 선형인지 선택한다.
- 비선형 사업은 중심선을 지정하거나 단일 연결 노선 검증을 통과할 필요가 없다.
- 선형 사업은 CAD 레이어별 임시 Shapefile을 현재 QGIS에 표시한 뒤 사용자가 중심선 레이어를 선택한다.

## 사용자 흐름

1. 사용자가 DXF를 선택하고 도면 분석을 실행한다.
2. Wizard가 `대상 사업이 선형 사업이십니까?`를 묻는다.
3. `아니요`를 선택하면 분석된 모든 지원 선 객체를 사업 객체로 사용한다. CAD 레이어 선택은 요구하지 않는다.
4. `예`를 선택하면 분석된 CAD 레이어마다 임시 Shapefile을 생성하고 현재 QGIS 프로젝트의 `RouteGIS 선형 후보 미리보기` 그룹에 추가한다. 지도 화면은 후보 전체 범위로 이동한다.
5. 사용자는 지도와 속성에서 객체 및 원본 CAD 레이어를 확인하고 Wizard 표에서 하나 이상의 중심선 레이어를 선택한다.
6. 공간정보 단계에서는 표시명, 내부 ID 또는 VWorld `data_id`로 필터링하고 필요한 항목을 체크한다.

## Geometry 규칙

- 선형 사업은 기존과 같이 선택된 레이어의 선 객체를 결합하고 분기 및 단절을 거부한다.
- 비선형 사업은 `LINE`, `POLYLINE`, `LWPOLYLINE`, `ARC` 객체를 모든 분석 대상 레이어에서 수집한다.
- 비선형 사업 객체는 연결성 또는 분기 검사를 하지 않고 개별 선 객체를 유지한 `MultiLineString`으로 저장한다.
- 사업구간 주변 범위는 모든 선 객체의 합집합을 기준으로 한 번에 Buffer한다.
- 문자, 치수, 블록 등 현재 지원하지 않는 비선형 DXF 객체는 대상에 포함하지 않는다.
- 비선형 산출물의 표시명은 `노선 중심선`이 아니라 `사업 객체`를 사용한다.

## 임시 Shapefile 수명주기

- Wizard 실행마다 전용 임시 디렉터리를 만든다.
- CAD 레이어별 선 객체를 조립하지 않은 개별 Feature로 내보내 원본 구조를 확인할 수 있게 한다.
- QGIS 레이어명에는 CAD 레이어명을 포함한다.
- Wizard가 종료되거나 새 DXF를 분석하면 이전 미리보기 레이어를 QGIS에서 제거한 뒤 임시 디렉터리를 정리한다.
- 미리보기 실패는 최종 프로젝트 폴더를 변경하지 않으며 사용자에게 원인을 표시한다.

## 데이터 및 호환성

- `ProjectConfig`에 명시적인 사업 유형을 추가하고 기본값은 기존 CLI 호환성을 위해 선형으로 둔다.
- Manifest에는 사업 유형과 실제 사용된 원본 CAD 레이어를 기록한다.
- CLI는 기존 동작을 유지하며 새 옵션이 없으면 선형 처리한다.
- VWorld 검색은 QListWidgetItem의 구조화된 사용자 데이터에 표시명, 내부 ID, `data_id`를 함께 저장해 표시 문자열에 의존하지 않는다.

## 검증

- 실제 `data_id` 검색 회귀 테스트.
- 분기된 DXF가 선형 모드에서는 실패하고 비선형 모드에서는 성공하는 통합 테스트.
- 비선형 AOI가 모든 객체의 범위를 포함하는지 검증.
- 임시 Shapefile이 CAD 레이어별로 생성되고 QGIS에서 유효하게 열리는지 검증.
- 설치된 QGIS 3.34에서 팝업의 `예`/`아니요`, 미리보기 그룹, 중심선 선택, VWorld 검색을 실제 조작한다.
