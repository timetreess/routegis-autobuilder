# QGIS 레이어 그룹명 한글화 설계

## 목표

생성되는 QGIS 프로젝트의 레이어 그룹명을 번호 순서는 유지하면서 한글로 표시한다.

## 그룹명 매핑

| 기존 그룹명 | 변경 그룹명 |
| --- | --- |
| `00_BASE` | `00_기본도` |
| `01_ROUTE` | `01_노선` |
| `02_CADASTRAL` | `02_지적` |
| `03_LANDUSE` | `03_토지이용` |
| `04_ADMIN` | `04_행정구역` |
| `05_FACILITY` | `05_시설물` |
| `99_SOURCE` | `99_원본자료` |

## 구현 범위

- Headless QGS 생성과 PyQGIS 네이티브 프로젝트 생성에서 동일한 그룹명을 사용한다.
- 레이어 분류, 그룹 순서, 레이어 표시명 및 데이터 구조는 변경하지 않는다.

## 확인 기준

샘플 QGZ의 레이어 트리에 위 7개 한글 그룹명이 순서대로 존재하고 기존 영문 그룹명은 존재하지 않아야 한다.
