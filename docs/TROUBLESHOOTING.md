# 문제 해결과 상세 동작

README의 [문제가 생기면](../README.md#문제가-생기면) 절을 보충하는 문서입니다. 오류 메시지별 확인 방법과, 인증키·네트워크·공간정보 수집이 실제로 어떻게 동작하는지 정리합니다.

## 인증키

| 공급자 | 필요한 값 | 발급처 |
|---|---|---|
| VWorld | VWorld API Key | [VWorld](https://www.vworld.kr) 개발자센터에서 인증키 발급 |
| 국립생태원 생태자연도 | 공공데이터포털 서비스키 | [공공데이터포털 생태자연도 WFS](https://www.data.go.kr/data/15057288/openapi.do)에서 활용신청 |
| OpenStreetMap | 없음 | - |

- 위저드 입력란의 값(저장된 입력 포함)을 가장 먼저 사용합니다. 입력란이 비어 있을 때만 환경변수(`VWORLD_API_KEY`, `DATA_GO_KR_SERVICE_KEY`) → 설치된 플러그인 폴더의 `.env` 순서로 찾습니다.
- 입력란을 비운 뒤 다른 곳을 클릭하거나 위저드를 닫으면 저장된 값도 삭제됩니다.
- 공공데이터포털 서비스키는 `Encoding`과 `Decoding` 형식 모두 입력할 수 있습니다.
- VWorld 공식 WFS 요청은 API Key만으로 동작하며 등록 도메인은 입력하지 않습니다.
- 입력한 Key는 현재 사용자의 QGIS 설정에 저장됩니다. 이 설정은 암호화된 저장소가 아니므로 공용 PC에서는 Key를 저장하지 마세요.
- Key는 생성된 QGIS 프로젝트, Manifest, 보고서, 로그, HTML 웹 지도에 기록하지 않습니다.

## 오류 메시지별 확인 방법

### `INVALID_KEY`, `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`

해당 공급자의 Key가 맞는지, 그 Key로 서비스 이용 신청이 승인되었는지 확인하세요. 공공데이터포털은 신청 직후 승인까지 시간이 걸릴 수 있습니다.

### `CERTIFICATE_VERIFY_FAILED`

API Key가 아니라 HTTPS 보안 연결 단계의 오류입니다. 사내 보안 프록시가 있는 PC에서 주로 발생합니다.

1. 전산 담당자에게 사내 보안 프록시의 루트 인증서가 Windows의 **신뢰할 수 있는 루트 인증 기관**에 등록되어 있는지 확인합니다.
2. 등록 후 QGIS를 완전히 종료했다가 다시 실행합니다.
3. 프록시를 쓰는 환경이면 QGIS의 **설정 → 옵션 → 네트워크**와 Windows 프록시 설정을 확인합니다.
4. 별도 CA 인증서 파일을 받았다면 `ROUTEGIS_CA_BUNDLE` 환경변수에 그 파일 경로를 지정합니다.

인증서 검증을 끄는 방식으로 우회하지 마세요. 인증서 오류는 재시도해도 해결되지 않으므로 바로 실패로 표시합니다.

### OpenStreetMap `HTTP 504`

Overpass 서버가 혼잡하거나 응답 시간을 초과했다는 뜻입니다. 잠시 후 다시 실행하세요.

- 기본 서버에서 일시 오류나 통신 오류가 나면 공개 대체 서버(`overpass.private.coffee`, `maps.mail.ru`)로 차례로 전환하고, 응답한 서버를 이후 요청에 우선 사용합니다.
- 타일당 전송은 최초 요청을 포함해 최대 3회, 서버 응답 대기는 180초입니다.

### OpenStreetMap까지 모두 실패

OpenStreetMap은 Key가 필요 없으므로, 이것까지 실패하면 Key 문제가 아니라 인터넷·DNS·프록시·방화벽 문제일 가능성이 큽니다. 함께 표시되는 네트워크 오류를 확인하세요.

### VWorld DNS 오류

VWorld 주소를 일시적으로 찾지 못하면 더 긴 간격으로 재시도합니다. 그래도 실패하면 인터넷 연결, DNS 서버, VPN·프록시 상태를 확인하세요.

### `해당없음`

조회는 정상적으로 성공했지만 분석 범위 안에 해당 객체가 없다는 뜻입니다. 실패가 아닙니다.

### 공간정보가 엉뚱한 곳에 표시되거나 "전혀 겹치지 않습니다"

원본 도면 좌표계가 잘못 선택되었을 가능성이 큽니다. 내려받은 데이터가 분석 범위와 전혀 겹치지 않으면 해당 레이어를 실패로 처리합니다. 도면 분석 화면에서 붉은 도면 선이 기본도의 도로·하천과 맞는 좌표계를 다시 고르세요.

### 최종 저장 실패

Windows에서 다른 프로그램이 프로젝트 폴더나 파일을 사용 중이면 저장이 막힐 수 있습니다. 오류 메시지에 표시되는 임시 결과 위치에 완성된 결과와 진단 로그가 보존되어 있습니다.

## 좌표계 추천

- **도면 분석**을 누르면 실제 선 객체의 X/Y 범위·중심과 DXF 단위(`$INSUNITS`)를 확인하고, 각 좌표계로 변환한 위치가 입력한 시·도 부근인 후보를 추천합니다.
- 사업 지역은 `경기도`, `전라북도`, `전북특별자치도`, `경기도 수원시`처럼 입력할 수 있고, 비워 두면 전국 범위로 찾습니다.
- 추천은 시·도의 대략적인 범위와 EPSG 사용범위를 이용한 후보 추리기입니다. 시·도만으로 Bessel/GRS80의 수백 m 차이까지 확정하지 않습니다. 동점 후보는 좌표계 목록 순서로 표시합니다.
- 지역 원점·임의 좌표, X/Y가 뒤바뀐 도면, mm 단위 도면에는 맞는 후보가 없을 수 있습니다. 자동 이동이나 축척 보정은 하지 않습니다.
- 미리보기 기본도(VWorld Street, VWorld Hybrid)를 보려면 인터넷 연결이 필요합니다.

## 진행 상태와 취소

- 도면 분석과 프로젝트 생성은 QGIS 화면을 멈추지 않도록 백그라운드에서 실행합니다.
- 진행률은 처리 단계 기준이며 남은 시간의 비율은 아닙니다. 경과 시간과 마지막 진행 알림 이후 시간은 매초 갱신되므로 오래 걸리는 서버 요청과 화면 정지를 구분할 수 있습니다.
- **생성 취소**를 누르면 현재 처리 단계나 서버 요청이 끝난 뒤 임시 결과를 정리하고 중단합니다.

## 공간정보 수집 방식

### 긴 노선과 밀집 지역

- 분석 범위를 공급자별 격자로 나눠 요청합니다.
- [VWorld WFS는 요청당 최대 1,000개](https://www.vworld.kr/dev/v4dv_wmsguide2_s001.do)만 반환하므로, 응답이 한도에 걸린 구간은 더 작게 나눠 다시 요청합니다. 여러 레이어를 묶거나 한도를 키우는 식으로 우회하지 않습니다.
- 토지소유정보처럼 전체 객체 수를 알려 주는 응답은 그 수를 이용해 밀집 구간을 처음부터 적절한 크기로 나눕니다.
- 시간 초과나 서버 자원 오류가 난 구간은 이미 성공한 구간을 유지한 채 실패 구간만 최대 4단계까지 더 작게 나눠 다시 요청합니다.
- API 인증 오류, 인증서 오류, 형식이 잘못된 응답은 재시도하거나 나누지 않습니다.

### 요청 상한

- 레이어마다 초기 요청 예산(`max(100, 초기 타일 수 × 16)`)을 정하고, 추가 분할이나 다음 페이지가 필요하면 예산을 늘립니다. 안전 상한은 **레이어당 5,000회**입니다.
- 장애 재시도만으로는 예산을 늘리지 않습니다. 서버의 일일 한도와 429 응답 제한도 그대로 따릅니다.
- 끝내 수집하지 못한 구간이 있으면 해당 레이어를 성공으로 표시하지 않습니다.

### 병렬 수집과 응답 재사용

- VWorld, 국립생태원, OpenStreetMap은 공급자별로 동시에 수집합니다. 같은 공급자 안에서는 레이어와 타일을 순서대로 처리해 서버 부하와 요청 수를 늘리지 않습니다.
- 송전선로와 송전철탑·지지물을 함께 선택하면 같은 타일의 성공 응답을 한 번 재사용합니다. 재사용 응답은 전체 64 MiB 이내로만 보관하고, 재사용한 타일은 Manifest의 `request_count`에 추가 전송으로 세지 않습니다.
- 하천구역·수면 조회에는 하천 중심선 요청을 포함하지 않습니다.
- 반복적인 요청·타일 진행 로그는 5초 경과 또는 25회 요청마다 요약하고, 실패·재시도·분할·예산 변경은 생략하지 않습니다.

### Geometry 처리

- VWorld의 잘못된 면 도형은 면적이 있는 모든 면 요소를 보존해 복구하고, 복구 과정에서 생기는 면적 0의 선·점만 제외합니다. 좌표변환 후 다시 유효하지 않게 된 도형도 같은 방식으로 복구합니다. 복구한 객체 ID는 진행 로그에 남깁니다.
- 생태자연도의 GML 2 좌표계 표기와 객체별 범위 메타데이터를 처리하되, 실제로 다른 좌표계를 같은 것으로 간주하지 않습니다.
- 분석 범위와 겹치는 객체는 잘라내지 않고 원형 그대로 보존하므로, 범위 밖 부분이 함께 보일 수 있습니다.

## Shapefile 인코딩

Shapefile 속성은 국내 CAD/GIS 프로그램과의 호환을 위해 EUC-KR로 저장합니다. EUC-KR로 표현할 수 없는 문자가 있는 레이어는 문자를 잃지 않도록 Shapefile을 만들지 않고 GeoPackage를 참조하며, 보고서에 경고를 남깁니다.
